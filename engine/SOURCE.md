# Stockfish.js Lite

The unmodified JavaScript and WebAssembly files are from the [Stockfish.js v19.0.1 release](https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1). The [matching source and build instructions](https://github.com/nmrugg/stockfish.js/tree/v19.0.1) are available upstream. See COPYING.txt (GPLv3). Opening Lens communicates with the engine as a separate process using UCI.
